# 易经 · 连续卦象 (Yi-Ching)

一个易经的可视化互动网站：模拟真实的起卦过程，给出本卦、之卦和对应的卦辞爻辞，并把六十四卦的离散顶点扩展到连续空间里观察。

**在线体验：<https://tongchen779.github.io/Yi-Ching/>**

纯静态页面，原生 JavaScript + Canvas，无构建步骤，无第三方依赖。

## 功能

### 起卦
- **大衍筮法（蓍草）**：按"分二、挂一、揲四、归奇"逐步模拟，每一爻三变，并有分堆动画（可选慢、快、跳过）。6、7、8、9 的出现概率为 1/16、5/16、7/16、3/16，与传统分析一致。
- **三钱法**：三枚铜钱，正面记 3、反面记 2，概率为 1/8、3/8、3/8、1/8。
- 两种方式后面的"？"，悬浮（手机上点击）可查看流程和说明。
- **断语**：按朱熹《易学启蒙》的变爻取辞法（0 到 6 个动爻）自动选出卦辞或爻辞，乾坤全变取用九、用六。

### 连续空间
六十四卦是 {0,1}⁶ 的顶点。页面把它扩展成连续空间，并用两种方式观察：

- **立方体**：每爻有一个"阳度" x ∈ [0,1]，任意点对 64 卦的权重为 ∏ xᵢ^hᵢ (1−xᵢ)^(1−hᵢ)（多线性插值）。拖动爻线，或点击立方体顶点；下卦和上卦各是一个可旋转的三维立方体，起卦后可用"变"滑块让动爻从本卦走到之卦。
- **环面**：每爻是四象环上的一个相位，少阳 → 老阳 → 少阴 → 老阴，顺时针。六个环是 T⁶ 的六个坐标，同时把"相应"的两爻（初应四、二应五、三应上）配成三个三维环面显示。离散格点正好是 4096 个（本卦, 之卦）状态。点"流转"，各爻以不同节律转动，越过"老"就是变。

卦辞不会连续变化，所以连续状态下的"叠加卦辞"只是按权重显示，并非新的经文。右侧有 64 卦的伏羲方图（行为下卦、列为上卦），亮度表示权重。

### 结合问题的解读
- 起卦前可写下想问的事（可选）。
- 占卜后生成一段包含问题、卦象、卦辞、爻辞和取辞法的**提示词**，可一键复制，粘贴给自己的 AI 助手。
- 也可点"**在线解读**"，通过 [Puter.js](https://developer.puter.com/) 直接在页面里流式生成。无需 API key，费用由访客自己的 Puter 账号承担（有每月免费额度，具体数额见 Puter 账户面板）。可选模型包括通义千问、DeepSeek、Claude、GPT、Gemini 等，默认是通义千问 3.8 Flash。

### 其他
- 深色 / 浅色主题切换，选择会保存在浏览器里，首次访问跟随系统。
- 适配手机：窄屏下先显示起卦与断语，再显示空间视图，并有吸顶摘要。

## 隐私
- 页面本身不收集、不上传任何内容，问题只留在你的浏览器里。
- Puter 的脚本只在你第一次点"在线解读"时才加载。点击之后，你的问题和卦象会发送给 Puter 及所选模型的提供方。不想发送，可以只用"复制提示词"。

## 本地运行
```bash
python3 tools/serve.py 8000
```
然后打开 <http://localhost:8000>。这个小服务器禁用了缓存，改完文件直接刷新即可。

页面通过页面自身的 `Last-Modified` 给资源地址加版本号（`style.css?v=…`），所以部署到 GitHub Pages 后不会被浏览器 10 分钟的缓存卡住旧文件。

## 目录结构
```
index.html            页面骨架与资源加载
src/
  data.js             64 卦数据（卦辞、爻辞、象、彖），由 tools/extract.py 生成
  divination.js       起卦逻辑：大衍筮法、三钱法、四象相位数学
  stalks.js           蓍草分堆动画
  torus.js            环面视图：四象环与三维环面
  prompt.js           把问题与卦象整理成提示词
  ai.js               Puter 在线解读
  theme.js            明暗主题
  app.js              状态、渲染、立方体、方图、断语
  style.css           样式（CSS 变量，含两套主题）
tools/
  extract.py          从维基文库 JSON 提取并生成 src/data.js
  serve.py            本地开发服务器
```

## 数据来源
原文取自[维基文库《周易》](https://zh.wikisource.org/wiki/周易)。`tools/extract.py` 从抓取好的 JSON 里提取每一卦的卦辞、六爻爻辞、用九 / 用六、彖、大象和小象，输出到 `src/data.js`。脚本里的 `SRC` 路径指向本机的抓取目录，在别处重新生成数据时需要改成你自己的路径。

使用原文时请遵守维基文库的许可条款。
